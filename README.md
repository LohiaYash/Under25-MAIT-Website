# 🎓 Under25 MAIT Website

A community-driven web platform built for MAIT students under the **Under25 ecosystem**, designed to centralize campus updates, events, and student engagement in one place.

## 📌 Overview

The **Under25 MAIT Website** is a student-focused digital platform that improves accessibility to campus events, updates, and community initiatives.  

It is designed to enhance communication within the MAIT student ecosystem and provide a clean, modern interface for browsing information related to Under25 activities.

This project focuses on **frontend engineering, UI/UX design, and scalable component architecture**.

---

## 🚀 Features

- 🏠 Modern and responsive landing page
- 📢 Event and announcement sections
- 🎨 Clean UI with Tailwind CSS styling
- 📱 Mobile-first responsive design
- 🧩 Reusable React components

- 🔗 API-ready structure for future backend integration

## 🎯 Problem Statement

Campus information is often scattered across multiple platforms, making it difficult for students to stay updated with events, announcements, and community activities.

This project aims to solve that by creating a **centralized and easy-to-access student hub**.
